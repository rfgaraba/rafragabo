Política de Privacidad

Última actualización: 30 de mayo de 2026

Esta política de privacidad describe cómo se maneja la información en el contexto del uso personal de la integración de WhatsApp Business API configurada por Rafael Garabato ("yo", "me").

1. Información que se recopila

La aplicación puede recibir mensajes de WhatsApp enviados al número de teléfono asociado, incluyendo el contenido del mensaje y el número de teléfono del remitente.

2. Uso de la información

La información recibida se utiliza exclusivamente para uso personal y automatización privada. No se comparte con terceros, no se vende, ni se utiliza con fines comerciales.

3. Almacenamiento

Los datos se procesan en un servidor privado de uso personal. No se almacenan en servicios de terceros salvo los necesarios para el funcionamiento técnico (Meta/WhatsApp Business API).

4. Terceros

Esta integración utiliza la API de WhatsApp Business de Meta Platforms, Inc. El uso de dicha API está sujeto a las Condiciones del Servicio de WhatsApp.

5. Derechos del usuario

Si recibiste un mensaje o interactuaste con este número y deseas que tus datos sean eliminados, podés solicitarlo escribiendo a: rafaelgarabato@gmail.com

6. Contacto

Para cualquier consulta sobre esta política: rafaelgarabato@gmail.com
